# P6-3 編集ページ (2026-09-29、開発サーバーで確認)

- `/k/[slug]/edit`(`src/app/k/[slug]/edit/page.tsx`・`EditPageClient.tsx`・`actions.ts`)。編集用URL `#key=<秘密キー>` の # 以降から秘密キーを読み(サーバーに送られない)、サーバーで確認してからエディタを出す。開いた後はアドレスバーから秘密キーを消す。
- # がないときは、このブラウザに保存した秘密キー(`src/lib/edit-keys.ts`)を使う。
- 配列ページには、このブラウザに秘密キーがある配列(自分の投稿)にだけ「編集する」ボタン(`src/components/OwnerEditLink.tsx`)。
- エディタ(`LayoutEditor`)に編集モードを追加: 「変更を保存する」で更新、「この配列を削除する」で削除(確認あり)。

## 確認(`cdp-edit.mjs`。一覧に出さないテスト投稿を作り、最後に削除する)12/12 成功
```
✓ 編集用URLで開くと、今の内容が入ったエディタが出る
✓ 開いた後、アドレスバーから秘密キー(#key=...)が消える
✓ 「変更を保存する」で保存できる
✓ 配列のページに編集後のタイトルが出る
✓ 自分の配列(このブラウザに秘密キーがある)には「編集する」ボタンが出る
✓ 他人の配列には「編集する」ボタンが出ない
✓ 違う秘密キーで開くと「編集できません」と出て、エディタは出ない
✓ 秘密キーなしで開いても「編集できません」と出る
✓ このブラウザに保存した秘密キーでも編集ページが開く(# なし)
✓ 削除すると「削除しました」と出る
✓ 削除した配列の秘密キーはこのブラウザから消える
✓ 削除した配列のページは404になる — 404
```
