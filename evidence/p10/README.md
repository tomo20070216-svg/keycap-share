# わかりやすさの改善 1〜4 (2026-10-06、開発サーバーで確認)

人間からの依頼「他にも分かりにくいところがあれば教えてください」に対する調査結果のうち、優先度の高い4件を実装した。

1. マクロがキー図に自動で反映されない点が伝わりにくい(`src/components/editor/ComboMacroEditor.tsx`)
2. 「ほかのキーと入れ替える」が今見ているレイヤーだけに効くことの強調が弱い(`src/components/editor/ElementPanel.tsx`)
3. ドラッグ中の枠が色だけで「置ける/置けない」を区別している(`src/components/editor/EditableKeymap.tsx`)
4. 「編集する」ボタンが、編集用の鍵を持たないブラウザでは何も表示されずに消える(`src/components/OwnerEditLink.tsx`)

## 確認結果

```
✓ 1: マクロの注記(自動で反映されません)が表示される
✓ 2: 要素パネルに「ほかのキーと入れ替える」ボタンがある
✓ 2: 「今見ている『◯◯』だけに効きます」という強調文がある
✓ 4: 編集用の鍵がないときにヒントが表示される — このブラウザには編集用の鍵がありません。投稿者の方は、保存時に表示された編集用URLを開いてください。
✓ 4: 「編集する」ボタンは出ない(鍵がないブラウザ)
```

3は、ヘッドレスChromeでCDPの `Input.dispatchMouseEvent` を使い、実際にキーをドラッグして確認した。

```
同種への移動中の outline (allowed想定): rgb(22, 163, 74) solid 4px
異種への移動中の outline (not allowed想定): rgb(220, 38, 38) dashed 4px
```

allowed(置ける/入れ替えられる)は緑の実線、not allowed(できない)は赤の点線になり、色だけでなく線の形でも区別できることを確認した。
