# P5-7 「コピーして編集」 (2026-09-29、開発サーバーで確認)

配列ページの「この配列をコピーして編集」→ `/new?from=<slug>`。元の配列のレイヤー・割り当て・コンボ・マクロ・タグを複製し、
投稿者名と「なぜこの配置にしたか」は投稿した本人のものなので複製しない。保存すると別の配列(新しいURL・新しい秘密キー)になり、
配列ページに「元にした配列」へのリンクを表示する。存在しない配列を指定すると404。

確認スクリプト: `cdp-fork.mjs`(ヘッドレスChrome)。結果 7/7 成功:
```
✓ 配列ページのボタンでエディタが開く — /new?from=orca-echo-combo-sample
  エディタの中身: {"title":"Orca echo コンボのサンプル配列","author":"","description":"","tags":"サンプル","tabs":["0: 通常","1: fn1(赤)","2: fn2(緑)"],"combos":true,"macro":["署名", ...],"m1":true}
✓ 元の配列の内容が入っている(レイヤー3つ・コンボ3つ・マクロ・M1の署名・タグ)
✓ 投稿者名と「なぜこの配置にしたか」は複製されない
✓ コピー元が分かる表示がある
✓ 保存すると新しい共有URLが発行される — http://localhost:3123/k/o7Wtzx4ONG8(一覧に出さないテスト投稿)
✓ 保存した配列のページに、元にした配列へのリンクがある — /k/orca-echo-combo-sample
✓ 保存した配列にもコンボが引き継がれている
```
