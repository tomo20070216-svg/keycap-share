## 表示のしかた
- コンボの対象キーは青い枠線で囲み、キーの内側の右上に番号の丸を置く。複数のコンボに入るキーは番号が複数(J=1・3、K=1・2、L=2・3)。
- 番号の丸は、フォントの丸数字(①など)ではなく図形で描く(OGP画像用のフォントで欠けるおそれがないように)。
- 最初はキーの右上の外側にはみ出して置いたが、上の段との境目にかかり、どのキーの番号か紛らわしかったため、内側に移し、番号のあるキーは文字を少し下げた。
- 一覧は「番号の丸 / キーの名前(工場出荷時の印字) / → 表示名 / (対象レイヤー)」の形。マクロは「名前 / 説明」。
- 番号は配列全体での並び順で、レイヤーによって変わらない。対象レイヤーを指定したコンボは、そのレイヤーの図にだけ番号が付く(テストで確認)。
