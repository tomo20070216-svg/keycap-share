## 確認できたこと
- タップは大きく、長押しは下に小さく表示(テストレイヤーの「A / Ctrl」「変換 / Shift」)。長押しだけのキーは長押しの文字だけ表示。
- 割り当てのないキーは空欄+薄い灰色(fn1・fn2レイヤー)。
- 長い文字は自動で小さくし、小さくなりすぎる場合は区切りのよい位置で2行に分ける(「2.4GHz / 切替」「ホイール / クリック」)。
- 傾いたキー(親指)も文字ごと傾く。

## 作業中に見つけて直した問題
- OGPの仕組み(Satori)は `transform: undefined` のようなundefinedの値でエラーになる → 回転があるときだけ付けるようにした。
- OGPの仕組みでは、フラグメント(<>…</>)の子が縦に並ばず、2行の文字が1行に並んではみ出した → 縦並びのdivで包むようにした。
- 画面幅が狭いとき、図の元の幅がページを押し広げていた → `contain: inline-size` で解消。

## 残っている課題(このタスクの合格条件の外)
- ダイヤル・トラックボール・スクロールパッドの操作は、要素の「中」に小さく並べている。トラックボール(操作が最大5つ)は文字がかなり小さい。当初の案「要素の周りに並べる」は、隣のキーと重なりやすい。実物に近い座標(P2-4)で周囲の空きが分かってから、人間と相談して決める。
- スマホ幅では全体が縮小されるため文字が小さい。閲覧ページ(フェーズ3)で見せ方を検討する。
- 画面側はNoto Sans JPを読み込んでいない(フォントファイルが5MBあり、Web表示には重いため)。ブラウザの標準フォントで表示している。
