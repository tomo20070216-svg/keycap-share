# レイヤーの数の上限を8つに(実行役、2026-09-30、人間の依頼)

- 上限は `src/lib/schemas.ts` の `MAX_LAYERS = 8`(通常を含めて8つ。以前は10)。エディタの「＋ レイヤーを追加」とサーバー側の検証の両方で使う。
- 保存済みの配列はどれもレイヤー3つ(本番DBを読み取りで確認: orca-echo-factory-default・Iywp3BUpM-g・orca-echo-combo-sample)なので、上限を下げても表示できなくなる配列はない。
- 単体テスト: 8つは受け付け、9つは「レイヤーは通常を含めて1〜8個にしてください。」/ エディタの追加は8つで止まる。`npm test` 17ファイル136件、`tsc`・`eslint`・`npm run build` 成功。
- 画面(開発サーバーの /new、投稿はしていない):
```
開いた直後: レイヤーのタブ 0: 通常 / 1: fn1(赤) / 2: fn2(緑)、追加ボタンは押せる、説明「…(最大8個)」
「＋ レイヤーを追加」を7回押した後: 0〜7 の8つで止まり、追加ボタンは押せない(disabled)
```

## 本番での確認(https://keycap-share.vercel.app/new 、push b21d309..903c719 のあと)
- 「＋ レイヤーを追加」を7回押すと 0〜7 の8つで止まり、追加ボタンは押せない。説明は「(最大8個)」。投稿はしていない。
- トップと保存済みの3つの配列ページ(Iywp3BUpM-g・orca-echo-factory-default・orca-echo-combo-sample)はすべて 200。
