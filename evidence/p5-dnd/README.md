## 作業中に見つけて直した不具合
1. **スマホ幅でエディタのキー図が小さすぎた**(キー1つ約20px)。閲覧ページ(P3-4)と同じく、狭い画面では左手・右手を縦に並べて大きく(約40px)表示するようにした。
2. **縮小表示の外枠がスクロールして、図が上にずれる**。縮小しても中のボタンの場所は縮小前の大きさのままなので、ボタンを画面内に出す処理(フォーカスなど)で overflow: hidden の外枠がスクロールしていた。overflow: clip にし、古いブラウザ向けにスクロールしたら戻す処理を追加(閲覧ページの図にも効く)。
3. **指で素早くタップすると、ブラウザが click イベントを出さないことがあり、タップが無視された**(4回中3回)。タップは click に頼らず、ポインターを離したときに「ほとんど動かしていなければタップ」として扱うように変更。click はキーボードで押したとき(detail === 0)だけ扱う。
4. 「ダイヤル(ダイヤル)」のように、印字と種類の名前が同じ要素で名前が重なっていた。

## 残っている制限
- スマホで左手と右手をまたいで入れ替えるには、両方の図が画面に入っている必要がある(縦に並べているため、画面の高さによってはドラッグが届かない)。PCでは問題ない。
