# P4-1 技術検証: Vercel上での ImageResponse と日本語フォント (2026-09-29)

## 方法
- 確認用ブランチ `preview/p4-1`(コミット 4304176)を push し、Vercel のプレビューデプロイを作成(本番ではない)。
- プレビューにはデプロイ保護(Vercelにログインした人だけが見られる)がかかっていたため、人間がログイン済みのブラウザで
  開発用ルート `/dev/og/orca-echo-factory-default` を開き、表示された画像を保存した(Vercelの共有リンクはトークン付きのものが作れなかった)。

## 結果
- `orca-echo-factory-default.png`: PNG、1200×630。タイトル「Orca echo 工場出荷時配列」、機種名・レイヤー名、キー配置図が文字化けなく描画された。
- 表示までの時間: 約2.5秒(人間の体感)。
- フォントは `public/fonts/NotoSansJP-Bold.ttf`(5.3MB)を `readFile` で読み込む方式のまま、Vercel上で動作した(`runtime = "nodejs"`)。

## 結論
- フォントは丸ごと使う(現状の方式)。ドキュメントの「500KB制限」は Edge 実行環境の制限で、nodejs 実行環境のルートでは問題にならなかった。
- 約2.5秒の生成時間は、画像URLに更新日時を含めたうえで CDN に長くキャッシュさせて対応する(P4-3)。同じURLの画像は内容が変わらないため、長期キャッシュしてよい。
- 使う文字だけに絞ったフォント(サブセット)は、手間が増えるわりに初回の生成しか速くならないため見送る。
