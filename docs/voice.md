# docs/voice.md — 画面の文言・共有文のトーン

対象読者が「分割キーボード初心者」であることを常に意識する。専門用語(QMK, Vial, レイヤーなど)を使うときは、初出時に一言添える。

## 基本方針

- 言語は日本語を主とする(英語対応は今回のスコープ外。必要になったら人間に相談)。
- 文体は「です・ます調」、親しみやすく、断定しすぎない。
- エラーメッセージは「何が起きたか」+「次に何をすればよいか」を書く。「エラーが発生しました」だけで終わらせない。
- 専門用語より「表示用の名前」を優先する(例: キーコード `KC_LCTL` ではなく `Ctrl` と表示)。`plan.md` 2章の方針4に対応。

## X共有時の初期文言

- ハッシュタグ例: `#OrcaEcho` `#分割キーボード`(投稿者が編集可能にする。固定文言として強制しない)。
- 初期テンプレート例: 「{タイトル} — {機種名}の配列を作りました { URL }」
- 「なぜこの配置にしたか」を書いた説明文は、文字数が多くなりがちなので共有文には含めず、リンク先ページに誘導する。

## 注意書きの文言例

- OGP画像のキャッシュについて: 「Xのカード画像は一度読み込まれるとしばらく更新されないことがあります。最新の見た目を確認したい場合は、Xのカード検証ツールなどをお試しください。」
